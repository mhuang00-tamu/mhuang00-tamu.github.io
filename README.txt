HARMONIA INSTITUTE OF CLASSICAL MUSIC EDUCATION
Static website project

PAGES
- index.html       Home
- history.html    History of the Violin
- violinists.html Famous Violinists
- concertos.html  Violin Concertos
- listening.html  Essential Listening
- 404.html        Custom not-found page

FEATURES
- Responsive layout with consistent navigation
- Mobile navigation menu
- Search and era filters on the Essential Listening page
- No backend or build process required
- External Google Fonts and Unsplash image URLs are used for visual presentation
- Recording links open YouTube searches for the named performance

RUN
Open index.html in a browser, or serve the folder using any static file host.
For GitHub Pages, upload the contents of this folder to a repository and enable Pages.
Configure your host to use 404.html as its custom not-found page if required.

NOTES
The website is an educational mock institution. The recording links are YouTube search links,
not guarantees that a particular official upload is available in every region.
The concerto tiers are a listener-friendly guide, not an objective technical ranking.
